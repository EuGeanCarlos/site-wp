# Site institucional em PHP

Estudo de site institucional com páginas PHP de início, sobre e contato. O processamento de formulário exige servidor PHP.

## Tecnologias

- PHP
- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Execute php -S localhost:8000 -t site-wp e abra http://localhost:8000. Revise a configuração de envio antes de usar o contato; há possível credencial versionada que exige revisão e rotação se real.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/site-wp.git
cd site-wp
```

Execute php -S localhost:8000 -t site-wp e abra http://localhost:8000. Revise a configuração de envio antes de usar o contato; há possível credencial versionada que exige revisão e rotação se real.

## Demonstração e publicação

Execução local. Nenhuma demonstração nova foi confirmada nesta etapa.

GitHub Pages hospeda arquivos estáticos e não executa Java, Node.js, PHP ou Python. As dependências de servidor deste projeto devem ser executadas em ambiente apropriado.
